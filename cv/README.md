# Instrucciones para tu Currículum Vitae (CV)

Para que el enlace "Descargar CV" en el portafolio funcione correctamente:

1. Guarda tu currículum en formato **PDF**.
2. Nombra el archivo exactamente como:
   `CV_Marcos_Vinicio_Reyes.pdf`
3. Coloca el archivo PDF dentro de esta carpeta (`cv/`).
4. Reemplaza el archivo existente cada vez que desees actualizar tu información profesional.

*Nota:* Asegúrate de subir los cambios a tu repositorio de GitHub para que se actualice en la versión publicada en GitHub Pages.
